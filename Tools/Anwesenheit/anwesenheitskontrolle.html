Auf den Laptop exportieren

Empfohlen ohne Excel: die HTML-Übersicht — eine einzige Datei für den Stick, öffnet sich per Doppelklick in jedem Browser.

Übersicht als HTML-Datei (kein Excel nötig)

Alle Listen (Namensliste, Matrix, Rohdaten) in einer Datei. Auf den Stick ziehen, auf dem Laptop doppelklicken — öffnet im Browser. Dort auch als PDF druckbar.

Weitere Formate (falls doch gebraucht):

Alles als Excel (.xlsx)

Eine Datei mit drei Blättern. Nur nützlich, wenn Excel oder LibreOffice installiert ist.

Namensliste (CSV)

Zwei Spalten: Klasse und Nachname, Vorname. Sortiert nach Klasse.

Anwesenheits-Matrix (CSV)

Eine Zeile pro Schüler, eine Spalte pro Datum, „X“ wo anwesend. Guter Wochenüberblick.

Rohdaten / Langformat (CSV)

Eine Zeile pro Anwesenheit: Datum, Klasse, Nachname, Vorname. Ideal zum Filtern.

Voll-Backup (JSON)

Sichert alle Daten. Auf der Tafel oder dem Laptop wieder importierbar.

Backup einlesen (JSON)

Eine zuvor gesicherte JSON-Datei laden. Daten werden zusammengeführt.
